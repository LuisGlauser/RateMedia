# Guia do Administrador

Acesse **Admin** no menu (aparece apenas para `role = admin`).

| Tela | O que fazer |
| --- | --- |
| Visão geral | Acompanhar obras, rascunhos, usuários e avaliações |
| Catálogo | Criar, editar e excluir obras; definir status editorial |
| Importar | Buscar no AniList/Jikan/TMDB e importar com um clique (sem duplicar) |
| Moderação | Limpar o texto de resenhas (a nota é mantida) e excluir avaliações de campanhas |
| Usuários | Promover ou rebaixar usuários (não é possível alterar o próprio papel) |
| Campanhas | Editar ou excluir qualquer campanha |
