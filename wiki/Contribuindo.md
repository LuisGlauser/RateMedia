# Contribuindo

Resumo do [guia de contribuição](https://github.com/LuisGlauser/RateMedia/blob/main/CONTRIBUTING.md):

1. Branch a partir da `main` com prefixo (`feat/`, `fix/`, `docs/`…).
2. Commits no padrão Conventional Commits.
3. Rode `npm run lint && npm run typecheck && npm test && npm run build`.
4. Abra o PR com o template preenchido e aguarde o CI e a revisão.

Labels, templates de issue e Dependabot ficam em `.github/`.
